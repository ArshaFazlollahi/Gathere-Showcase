# Screenshot gallery and capture notes

The JPEG files in `assets/screenshots/` were captured from the actual running local
Gathere demo on October 4, 2026. They are not AI-generated, edited mockups, or
evidence of a publicly hosted deployment. Captures use the browser's compact
responsive viewport; other screen sizes use responsive layouts.

| Capture | What it demonstrates |
| --- | --- |
| [City discovery, dark](../assets/screenshots/explore-cities-dark.jpg) | Gathere identity, city search, theme switch, and two-view navigation |
| [Event feed](../assets/screenshots/event-feed.jpg) | Thumbnail-led card, event-specific title, concise description, and custom sort control |
| [Event detail](../assets/screenshots/event-details.jpg) | AI quick read alongside a fuller description of a specific event |
| [Source provenance](../assets/screenshots/source-provenance.jpg) | Publisher links, location/cost facts, organizer verification reminder, and save action |
| [Campus discovery](../assets/screenshots/explore-campuses.jpg) | Institution selection and campus-specific identity |
| [Campus filters](../assets/screenshots/campus-filters.jpg) | Custom campus-life selector and shared discovery controls |
| [City discovery, light](../assets/screenshots/explore-cities-light.jpg) | The alternate light theme without changing the discovery workflow |

Event dates, availability, counts, and model-enrichment status can change. Some
screenshots show official publisher photography; the application's stock fallback
photos are illustrative and do not depict the exact event. A displayed popularity
signal is an application heuristic, not verified attendance or a guarantee.
